# Documentation index

This repository is one robotics project: **Lighthouse**, an agent-guided mobile robot that
maps a seven-room house in Gazebo Fortress, navigates it with Nav2, explores it autonomously,
and takes instructions in natural language from a local LLM.

Three entry points, depending on what you want:

| You want to… | Start here |
|---|---|
| **Understand the design** (newcomer, reviewer) | [`book/lighthouse-textbook.pdf`](book/lighthouse-textbook.pdf) — 63 pages, English |
| **Present it to others** | [`slides/lighthouse-navigation.pptx`](slides/lighthouse-navigation.pptx) — 19 slides, English |
| **Run or modify the code** | [`../README.md`](../README.md) — the hands-on manual (Chinese) |

## The textbook

`book/lighthouse-textbook.pdf` is the reference document: design principles, the simulated
world, the sensor contract, SLAM, Nav2, exploration experiments, the agent layer, preemption,
the acceptance gates, the frozen delivery set, and an honest list of what the project does
*not* do. Sources are in `book/src/*.md`; figures are generated from repository data by
`book/make_figures.py`; the PDF is built by `book/build_pdf.sh`.

## The slides

`slides/lighthouse-navigation.pptx` follows the same spine as the textbook, condensed to 19
slides for a talk. `slides/lighthouse-navigation.pdf` is a rendering for people without
PowerPoint. Rebuild with `book/build_pptx.py`.

## Rebuilding the documents

All three are regenerated from the repository — no hand-written numbers.

Prerequisites: `pandoc`, a TeX distribution with `xelatex`, the Noto CJK fonts, `graphviz`,
and the Python packages `matplotlib` and `python-pptx`
(`python3 -m pip install --user matplotlib python-pptx`).

```bash
# 1. figures (9 PNGs into docs/book/figures/)
#    floorplan from config/semantics.json, coverage curve decoded from the checkpoint
#    maps, 3x3 arms from experiments/ab_explore.csv. Needs matplotlib + graphviz.
/usr/bin/python3 docs/book/make_figures.py

# 2. the textbook PDF (63 pages). Needs pandoc + xelatex + Noto CJK fonts.
#    The script copies the sources first: it replaces ✅/❌ with PASS/FAIL (the fonts
#    lack those glyphs) and prepends chapter numbers (the .md headings carry their own
#    section numbers, so pandoc must not number them twice).
bash docs/book/build_pdf.sh

# 3. the slides (19 slides). Needs python-pptx.
/usr/bin/python3 docs/book/build_pptx.py
```

Sanity check after building: `build_pdf.sh` prints the page count and the number of
missing-glyph and overfull-box warnings — both should be `0`.

## What is *not* in this repository

`experiments/*_eval.jsonl` (per-trajectory evaluation dumps, 100–700 MB each) are excluded.
The derived metrics are in `experiments/ab_explore.csv`; the dumps are regenerated by
re-running a campaign with `tools/explore_ab.py`.
